# Layers of Meaning

A data-driven visualization project exploring how thematic focus differed between official publications and street broadsides in Scotland from 1800 to 1850.
[View Full Project PDF](./Layers_of_meaning.pdf)

[Watch Demo Video](https://youtu.be/mw0BRKU2h9o?si=3zQ5htFdNoSL9hHi)

## Overview

Layers of Meaning transforms historical publication data into an interactive visual experience. The project compares two types of material from the National Library of Scotland: official publications and everyday street broadsides.

A key challenge was developing a reliable classification method for historical texts. Initial Python keyword-based classification produced a large number of unknown and inaccurate labels, which led us to explore Large Language Models as an alternative.

## My Role

**Data Processing · AI Evaluation · Analytical Framework · Product Interaction Design**

My main contributions included:

- cleaning and structuring the historical dataset
- developing the analytical and classification framework
- implementing and evaluating Python keyword-based classification
- comparing Python classification with LLM-based classification
- designing a human evaluation process to validate model performance
- using confusion matrices and sample-based verification to assess accuracy
- supporting the interaction logic of the final visualization
- connecting the processed dataset to the interactive website

## From Data Problem to Product Decision

The initial keyword-based method generated many uncertain or inaccurate classifications.

To determine whether an LLM could provide more reliable results, I compared both approaches against manually classified samples. Human evaluation and confusion-matrix analysis showed that the LLM results were closer to human judgement.

Based on this evidence, the LLM-based classification was selected for the final dataset.

This process turned model selection into a data-informed product decision rather than relying on AI output without validation.

## Final Outcome

The final interactive website allows users to:

- compare thematic patterns between publications and broadsides over time
- explore individual topic categories
- inspect publication-level information
- understand how AI classification differs from human classification

## What I Learned

This project strengthened my ability to use data and AI critically in product development — from identifying data-quality problems and evaluating alternative models to translating validated results into an interactive product.
